# kill-ai-prose

A prompt that stops language models from writing like language models. Use it for technical docs, product copy, release notes, and anything else that goes out under your name.

The prompt is in [human-writing-prompt.md](human-writing-prompt.md). Paste it into a system prompt, custom instructions, a Claude Project, or a CLAUDE.md file. The context block at the bottom is filled in for this repo's owner. If you're using the prompt elsewhere, replace that block with your own audience, destinations, house style, and two to five samples of your writing. The samples matter more than any single rule.

## What it covers

Rhetorical patterns like "it's not X, it's Y", reflexive groups of three, setup-and-reveal questions, and punchy fragments. Inflated vocabulary and filler transitions. Formatting habits such as em dashes, bold-first bullets, emoji headers, curly quotes, and Unicode arrows. Document-level habits like recap openings, signposted conclusions, and restating one point in every section. It ends with a self-check the model runs before it outputs anything.

## Notes

Style instructions fade over long sessions. If output starts drifting, paste the prompt again.

The word lists will age as models change. The structural rules hold up longer.
